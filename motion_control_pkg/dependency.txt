添加ros2官方源
1.添加 Key:
  sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
  (若 raw.githubusercontent.com 打不开，可跳过此步直接使用清华源提供的 keyring 方式，或者手动下载)
2. 修改源地址为清华源:
  echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
3.更新并安装:
  sudo apt update
  sudo apt install ros-humble-ompl ros-humble-ruckig ros-humble-pinocchio等
  sudo apt install ros-humble-tf2 ros-humble-tf2-ros ros-humble-tf2-geometry-msgs
