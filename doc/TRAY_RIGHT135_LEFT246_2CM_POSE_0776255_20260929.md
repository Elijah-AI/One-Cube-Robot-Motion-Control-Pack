# Tray 右1/3/5、左2/4/6槽上方2 cm：新右下角位姿

2026-09-29；仅生成命令，未执行运动或进行IK、路径测试，未修改任务YAML。

原始视觉位姿已在base_link，单位m、四元数xyzw：
```yaml
position: [0.7762547731399536, -0.036875735968351364, 0.7930452823638916]
orientation: [-0.013940413482487202, -0.008642761036753654, 0.012897425331175327, 0.9997822046279907]
```

沿用当前任务补偿：局部X=0.205 m；槽1..6局部Y=[0.019,0.030,0.0653,0.077,0.132,0.142] m；目标为视觉局部Z=+0.020 m。

p_tcp=p_tray+R(normalize(q_tray))*[0.205,y_slot,0.020]；q_tcp=normalize(q_tray*q_offset)。右臂q_offset=[sqrt(0.5),-sqrt(0.5),0,0]，左臂q_offset=[sqrt(0.5),sqrt(0.5),0,0]。

固定腰腿的单臂MoveP，每次单独执行一条；速度0.05、自碰撞检查1，不包含预转腰、调腿或夹爪动作。

  target_pose: {
    header: {frame_id: base_link},
