# .136 任务 Modbus 隔离与重复触发修复

任务入口只监听 `127.0.0.1:12000`，保留 ROS_DOMAIN_ID 和现有运控、视觉通信。
外部设备（包括 172.16.20.66）不能通过网络直接连接任务 Modbus；在机器人本机运行 mbpoll。

Modbus 使用有界轮询同时管理最多64个连接，按 MBAP 长度组帧；空闲、半包、异常报文或断开的客户端不会独占服务。
未完成请求超过1秒断开；写入端已断开的缓冲请求丢弃。
任务启动交给 ROS executor，通信线程只完成寄存器操作和一个空闲请求的交接。

只在 IDLE 接受一次触发；运行中、已有交接请求或安全任务执行中拒绝重复触发，
不缓存下一轮任务。完成或失败后只回 IDLE，不自动重跑。
当前任务的状态寄存器绑定已接受的触发地址，不随其他寄存器写入改变。

```bash
# 此命令会开始真实装配；仅在反馈完整、新鲜且现场准备好时发送一次。
mbpoll -m tcp -p 12000 -a 1 -t 4 -0 -r 9 -1 127.0.0.1 0
mbpoll -m tcp -p 12000 -a 1 -t 4 -0 -r 9 -1 127.0.0.1 1
# 状态：1运行中、2成功、3失败
mbpoll -m tcp -p 12000 -a 1 -t 4 -0 -r 10009 -c 1 -1 127.0.0.1
```

寄存器写入回显不等于任务被接受；检查任务日志中的启动/拒绝记录。
本次通信修复不改变抓取目标、姿态、IK 或运动算法，不保证原先失败的轨迹可解。
