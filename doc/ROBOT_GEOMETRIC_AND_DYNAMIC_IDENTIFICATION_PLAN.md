# 当前机器人几何尺寸标定与动力学参数辨识方案

- 整理日期：2026-10-20。
- 适用工作区：`/home/elijah/ylf_wbc`。
- 阶段：调研与方案设计，暂不编写辨识程序。
- 核对范围：本地源码、URDF、工具配置及已安装库；未连接机器人，未执行实机运动。
- 数值性质：本文引用的机器人尺寸和质量是本地模型标称值，不是实测结果，也不代表机器人当前加载的配置。

## 1. 推荐路线

采用 **“几何标定 → 工具与力矩标定 → 单臂动力学辨识 → 腿腰与全身验证”** 的路线，计算核心继续使用 `ylf_wbc` 已有的 Pinocchio、Eigen、Coal、Ruckig/TOPPRA。

“尺寸辨识”理解为关节轴位置、连杆间变换、零位和 TCP 的几何标定；动力学辨识估计质量、质心、惯量及摩擦。两者分阶段进行，避免几何误差被错误吸收到动力学参数中。

首期优先完成实际工具清点与称重、TCP/单臂几何标定、力矩单位和时序核验、单臂动力学候选模型及独立验证。结果用于改善抓取装配、负载估计和全身质心计算；腿腰及移动底盘动力学作为后续阶段推进。

## 3. 参考文章与 GitHub 项目的使用方式

指定文章适合借鉴其数据管理和验证流程：冻结模型及工具配置、保留原始数据、使用独立验证轨迹、候选参数经过验证后再导入。它也强调力矩来源和时间对齐，这正是当前工程需要先补齐的基础。

文章：[机器人动力学参数辨识：从数据采集到安全验证](https://chase6305.github.io/posts/robotics/dynamics/parameter-identification/)。

| 项目 | 建议借鉴的部分 | 在当前机器人上的用途 |
|---|---|---|
| [FIGAROH / figaroh-plus](https://github.com/thanhndv212/figaroh-plus) | 基于 URDF、Pinocchio 的几何标定和动力学辨识，基参数提取、物理参数恢复 | 首选参考框架，最接近当前技术栈 |
| [robot_calibration](https://github.com/mikeferguson/robot_calibration) | 联合优化关节零位、坐标变换和相机参数 | 参考腿腰—双臂—相机的标定组织方式 |
| [BIRDy](https://github.com/TUM-ICS/BIRDy) | OLS、WLS、IRLS、IV 等辨识方法对比 | 用作算法验证参考，无需把 MATLAB 引入控制工程 |

## 4. 几何尺寸辨识

### 4.1 首轮参数范围

第一轮只释放影响大、容易观测的参数：

| 标定对象 | 首轮参数 | 采集方式 |
|---|---|---|
| 左右 TCP | 末端到工具的平移；有姿态测量时加入旋转 | 标准球、固定尖点或刚性标靶 |
| 双臂 | 各关节零位、肩部安装变换、主要连杆尺寸偏差 | 固定腿腰，采集多姿态末端测量 |
| 腿腰 | 4 轴零位、主要长度与安装角偏差 | 固定手臂构型，测量躯干或末端随腿腰运动的位置 |
| 全链 | 两臂相对位姿、腿腰姿态变化后的末端误差 | 独立工作空间测点 |

不建议第一轮把每个关节的六维安装误差全部开放。多个参数可能产生几乎相同的末端误差，最终虽能拟合数据，却无法确定真实尺寸。

FIGAROH 和基于 POE 的标定项目提供了可辨识参数筛选的参考：[FIGAROH](https://github.com/thanhndv212/figaroh-plus)、[robot-arm-kinematic-calibration](https://github.com/PhilNad/robot-arm-kinematic-calibration)。

### 4.2 测量设备与独立基准

- 有激光跟踪仪或可靠光学测量系统时，用它建立独立外部基准。
- 使用现有相机时，采用刚性标靶，先评估相机重复性、尺度与外参。不能用当前机器人 FK 生成的“测量值”来验证同一套 FK。
- 设备有限时，可用已知间距的标准球窝或多个约束面做位置标定，但姿态和部分几何参数的可观测性会受限。相关参考：[MUKCa 标定项目](https://github.com/platonics-delft/kinematics_calibration)。

### 4.3 采集设计

建议首轮每臂规划约 80–150 个静态姿态，另留 30–50 个独立验证姿态。这是采集预算，不是保证充分的固定数量。

姿态需覆盖不同肘形、腕部方向和实际装配区域，并安排同一点从正反方向接近，以区分零位误差与回差。每个观测使用对应静止时刻的实际编码器读数，统一关节方向、弧度、米和坐标系约定。

### 4.4 拟合方法

拟合形式为：

$$
\min_{\theta_g}
\sum_k
\left\|
\operatorname{Log}\!\left(
T_{\mathrm{meas},k}^{-1}
T_{\mathrm{FK}}(q_k;\theta_g)
\right)
\right\|_{W_k}^{2}
+\|\theta_g-\theta_{g,0}\|_\Lambda^2
$$

其中：

- $\theta_g$ 为待标定的几何参数，$\theta_{g,0}$ 为标称值。
- 平移与旋转按测量精度分别加权。
- 只有位置测量时，只使用位置残差。
- 固定一个参考坐标系，避免测量基座、机器人基座和工具变换之间互相补偿。

最终输出应是几何修正量、可辨识性和验证误差，不能仅报告“优化收敛”。

几何标定后若误差仍明显随负载变化，再单独考虑关节或结构柔顺性，避免把受力变形拟合为连杆尺寸。

## 5. 动力学辨识

### 5.1 从单臂固定基座实验开始

第一阶段条件：

- 底盘保持固定，腿腰保持不动。
- 另一侧手臂固定。
- 被辨识手臂在自由空间运动。
- 工具配置和负载明确。

采用的模型为：

$$
\tau_{\mathrm{meas}}
=
Y(q,\dot q,\ddot q)\pi
+F_v\dot q
+F_c\,\mathrm{sgn}(\dot q)
+J_r\ddot q+b
$$

各项含义：

| 项 | 含义 |
|---|---|
| $Y\pi$ | 刚体惯性、科氏/离心及重力项 |
| $F_v,F_c$ | 黏性与库仑摩擦 |
| $J_r$ | 等效关节侧转子惯量；是否可辨识需与其他惯性列联合检查 |
| $b$ | 力矩测量偏置 |

### 5.2 参数顺序与坐标系

Pinocchio 负责生成 $Y$。本地接口使用的每刚体参数顺序为：

$$
\pi_i=
[m,\;mc_x,\;mc_y,\;mc_z,\;
I_{xx},I_{xy},I_{yy},I_{xz},I_{yz},I_{zz}]^T
$$

这里惯量是连杆坐标原点处惯量，不能直接当作 URDF 质心处惯量填写，需要正确处理平行轴变换及惯性坐标系旋转。现有 SDK 工具参数的惯量排列也与此不同，后续必须明确转换。

本地核对依据：

- `/opt/ros/humble/include/pinocchio/src/spatial/inertia.hxx` 中的 `toDynamicParameters` / `FromDynamicParameters`。
- `/opt/ros/humble/include/pinocchio/algorithm/regressor.hpp` 中的 `computeJointTorqueRegressor`。

### 5.3 力矩来源标定

先确认力矩是总驱动力矩、外力矩估计，还是已扣除重力的残差。后两者不能直接代入上述总动力学方程。

若实际只有未标定电流，电流增益与惯性参数会存在尺度混淆，应先用已知负载或独立测力建立尺度。需要确认减速比、方向、力矩常数、效率及电流零偏的定义。

如果力矩传感器位于减速器输出端，摩擦和转子惯量的建模边界应随传感器位置调整。

### 5.4 实验顺序

| 顺序 | 实验 | 解决的问题 |
|---|---|---|
| 1 | 空工具和已知质量、已知力臂负载的静态姿态对比 | 检查力矩符号、尺度、偏置和工具重力响应 |
| 2 | 多姿态静态/准静态采集 | 估计可观测的质量与一阶质量矩组合 |
| 3 | 多档速度、正反向近恒速运动 | 分离摩擦与重力影响 |
| 4 | 多关节、多谐波动态轨迹 | 激励惯性及关节间耦合 |
| 5 | 不同轨迹、不同姿态、已知负载验证 | 判断参数是否能预测新数据 |

静态负载实验不能一次确定所有力矩增益，需让负载在各关节形成足够且不同的力矩。

### 5.5 动态激励轨迹

可采用多谐波轨迹：

$$
q_j(t)=q_{0j}
+\sum_{k=1}^{K}
\left[a_{jk}\sin(k\omega t)+b_{jk}\cos(k\omega t)\right]
$$

建议先以 3–5 个谐波作为候选，不直接规定统一频率和幅值。根据真实反馈带宽、噪声、可用空间和驱动限制筛选。

设计目标是改善归一化后回归矩阵的信息量，同时满足位置、速度、加速度、jerk、碰撞以及现有 J6/J7 组合约束。

Ruckig 可用于平滑进入和退出实验姿态，Coal 用于碰撞检查。TOPPRA 若改变轨迹时间参数，必须重新检查辨识信息量。

最终拟合使用实测运动，不能把参考轨迹的解析导数当作机器人实际速度、加速度。

## 6. 数据采集与离线求解

### 6.1 数据契约

后续采集至少保存：

| 类别 | 必要内容 |
|---|---|
| 时间 | 设备序号、采集时间、接收时间，区分新帧和重复读取 |
| 运动 | 具名实际关节位置、速度；指令值另存用于诊断 |
| 力矩 | 原始 effort/电流、换算后的关节力矩、换算依据 |
| 状态 | 控制模式、故障、饱和、温度、工具和负载配置 |
| 版本 | URDF、TCP、SDK、配置及软件版本 |

建议评估 100–250 Hz 的真实同步采样能力，再据此确定激励频带；不能通过重复读取补出采样率。

对 SDK 与 EtherCAT 两条数据链，应分别识别延迟，再确认跨链同步是否满足腿腰联动辨识需求。

### 6.2 可辨识性分析

对堆叠回归矩阵做列尺度归一化、QR/SVD，分清结构上不可辨识与当前轨迹激励不足。

不能把每连杆十个参数都宣称为独立辨识结果。固定连接的部件还会在动力学模型中合并，实验往往只能识别合并后的惯性，不能唯一拆回每个原始 URDF link。

输出应明确哪些来自数据、哪些保留 CAD 先验。

### 6.3 基参数拟合

用 Eigen 的 QR/SVD 建立最小二乘基线，再按噪声采用 WLS；少量异常点可用鲁棒损失。

若闭环测量噪声造成明显偏差，再参考 BIRDy 的 IV 等方法：[BIRDy](https://github.com/TUM-ICS/BIRDy)。

### 6.4 物理参数恢复

结合 CAD、称重和几何范围，约束质量、质心和惯量，恢复适合模型使用的完整参数。

可参考 log-Cholesky 参数化；若选择 LMI/半正定规划，需要额外求解器，现有 qpOASES 不能直接替代 SDP 求解器。

相关实现：[legged_robot_system_identification](https://github.com/ShahramKhorshidi/legged_robot_system_identification)。

## 7. 腿腰与整机验证

### 7.1 腿腰辨识

完成双臂后，锁定或带先验约束地使用已辨识的手臂参数，再辨识腿腰。

实验包括双臂收拢、伸出等不同构型，以及腿腰低速和动态轨迹，使下肢承受的上身惯性发生变化。

### 7.2 整机称重与质心验证

固定底盘时，底盘自身质量、质心和惯量不能由上身关节力矩完整辨识。

建议增加整机静态称重：

1. 各支撑点设置测力装置，记录真实支撑位置及反力。
2. 在无其他外力、水平静止条件下，由反力总和获得总质量，由力矩平衡获得水平质心。
3. 改变上身姿态，比较实测水平质心与模型预测。
4. 单一水平称重不能得到质心高度和完整转动惯量，需额外测量条件或继续保留 CAD 先验。

现有全身质心模型已使用 FreeFlyer 保留根连杆质量，这部分可以复用。辨识工具应保持独立的关节映射，不改变现有 IK 索引。

实现依据：[centroidal_model.cpp](../src/motion_control_pkg/src/wbc/centroidal_model.cpp)。

## 8. 验收指标

验收重点是独立数据上的改善：

| 层级 | 验收指标 |
|---|---|
| 几何 | 独立测点位置/姿态 RMS、P95、最大误差；双臂相对位姿误差 |
| 动力学 | 每轴力矩 RMSE、偏置、峰值残差；按位置、速度、加速度检查残差 |
| 物理合理性 | 正质量、合理质心、惯量正定及主惯量三角不等式 |
| 重复性 | 不同批次、温度和运动方向下的参数及预测稳定性 |
| 全身 | 总质量、水平质心预测与称重结果的一致性 |

几何精度目标由装配容差与测量系统决定。动力学同时报告 N·m 绝对误差和相对误差，不能用接近零的力矩作百分比基准。

验证集按整条轨迹或整次实验隔离，避免相邻样本随机拆分造成虚假的泛化效果。
